2. USERS, GROUPS,
AND IDENTITY SECURITY

LOCAL USERS AND SYSTEM ACCOUNTS

Linux uses local users and system accounts to manage access and ownership. System accounts usually have low UIDs and no login shell.

KEY ACCOUNT FILES

Three files control user identity: /etc/passwd (user list), /etc/shadow (passwords), and /etc/group (groups).

PASSWORD AGING AND EXPIRATION

Control password lifecycle with chage: set max age, expiration date, and warning days. Enforce rotation to reduce risk.

PAM POLICIES

Pluggable Authentication Modules enforce password complexity, lockout, and session policies via /etc/pam.d/.

KEY ACCOUNT FILES
/etc/passwd

KEY COMMANDS
id Show user and group identity
usermod Modify user properties
chage -l user List password aging info
Never edit /etc/shadow or /etc/passwd directly. Always use usermod and chage.
