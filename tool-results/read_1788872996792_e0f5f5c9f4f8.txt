   363→OWNER, GROUP, AND OTHER PERMISSIONS
   364→Every file and directory has three types of access:
   365→Owner (user), Group, and Other (everyone else).
   366→Permissions control what each can do.
   367→
   368→READ, WRITE, AND EXECUTE
   369→
   370→R (read): View file contents or list directory.
   371→
   372→W (write): Modify file or create/delete in directory.
   373→X (execute): Run file or access directory.
   374→
   375→NUMERIC AND SYMBOLIC PERMISSIONS
   376→Numeric: Use numbers (0-7) to represent permissions.
   377→Symbolic: Use letters (r, w, x) to set permissions.
   378→Example: 755 = rwxr-xr-x
   379→
   380→CHMOD, CHOWN, CHGRP
   381→
   382→chmod _: Change file or directory permissions
   383→chown _: Change file or directory owner
   384→chgrp_: Change file or directory group
   385→
   386→DIRECTORY PERMISSION BEHAVIOR
   387→Read (r): List files in the directory
   388→
   389→Write (w): Create, delete, or rename files
   390→Execute (x): Enter and access the directory
   391→Without x, you cannot access files inside.
   392→

   394→
   395→The umask sets default permissions for new files
   396→and directories.

   398→It determines what permissions are removed by
