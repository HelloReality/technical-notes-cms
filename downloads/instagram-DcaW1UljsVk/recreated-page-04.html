2. Shell Commands You Must Know First
Navigate · Create · View · Paths · Combine · Read · Practice
1. Navigate Your File System
pwdPrint working directory · pwd → /home/user
lsList files and folders · ls → file1.txt docs images
cd [dir]Change directory · cd docs (moves into docs)
cd ..Go up one directory · cd .. (moves up one level)
cd ~Go to your home directory · cd ~ → /home/user
2. Create, Copy, Move, Delete
mkdir [dir]Create a new directory · mkdir new_folder
touch [file]Create an empty file · touch notes.txt
cp [src] [dest]Copy files or folders · cp file1.txt backup.txt
mv [src] [dest]Move or rename files/folders · mv old.txt new.txt
rm [file]Remove (delete) files · rm temp.txt
3. View File Content
cat [file]Display entire file · cat notes.txt
less [file]View file page by page · less largefile.log
head [file]Show first 10 lines · head file.log
tail [file]Show last 10 lines · tail file.log
4. Absolute vs Relative Paths
ABSOLUTE PATH (full from root)
/home/user/docs/file.txt
  • Starts from the root /
  • Always points to the correct location
RELATIVE PATH (based on current location)
Current: /home/user
docs/file.txt
  • Does not start with /
  • Depends on where you are
5. Combining Commands
;Run commands one after another · mkdir test ; cd test ; touch file.txt
&&Run next only if first succeeds · mkdir test && cd test
||Run next if first fails · mkdir test || echo "Failed"
|Send output to another command · ls -l | less
>Redirect output (overwrite) · ls > output.txt
>>Redirect output (append) · echo "Hi" >> notes.txt
6. Reading Command Output
ls -l Lists files in long format.
ls -l | less Sends output to less so you can scroll.
cat file.txt | head -n 5 Shows first 5 lines of a file.
grep "error" app.log Searches for the word "error".
7. Beginner Practice Exercise — 12 Steps
1Show where you are
pwd
2List files and folders
ls
3Create a folder
mkdir practice
4Go into the folder
cd practice
5Create a file
touch hello.txt
6Write something in the file
echo "Hello" > hello.txt
7View file content
cat hello.txt
8Copy the file
cp hello.txt hello_copy.txt
9Rename the file
mv hello_copy.txt renamed.txt
10List files to see changes
ls -l
11Go back one directory
cd ..
12Remove the folder
rm -r practice
