7. Conditional Statements

Make smart decisions in your scripts.
1. Basic Syntax
if [ condition ]; then commands elif [ condition ]; then commands else commands fi
ifStart conditionthenRun if trueelifElse if another conditionelseRun if all falsefiEnd condition
2. Numeric Comparisons
OpMeaning
-eqEqual
-neNot equal
-gtGreater than
-ltLess than
-geGreater or equal
-leLess or equal
if [ $a -eq $b ]
3. String Comparisons
OpMeaning
=Equal
!=Not equal
-zString is empty
-nString not empty
if [ "$a" = "$b" ]
Note: Always quote strings! Prevents errors with spaces.
4. File Tests
OpMeaning
-fFile exists
-dDirectory exists
-eFile or dir exists
-rReadable
-wWritable
-xExecutable
-sFile is not empty
if [ -f file.txt ]
5a. Check File
bash
if [ -f /etc/passwd ]; then echo "File exists" else echo "File not found" fi
5b. Check Directory
bash
if [ -d /var/log ]; then echo "Directory exists" else echo "Directory not found" fi
5c. Check Service
bash
if systemctl is-active --quiet nginx; then echo "Nginx is running" else echo "Nginx is not running" fi
6. Practical Example
Check disk space and act based on the result.
bash
USAGE=$(df / | awk 'NR==2 {print $5}' | tr -d '%') if [ "$USAGE" -gt 80 ]; then echo "Disk usage is high: ${USAGE}%" elif [ "$USAGE" -gt 60 ]; then echo "Disk usage is moderate: ${USAGE}%" else echo "Disk usage is normal: ${USAGE}%" fi
7. Quick Reference
  • if Start condition
  • then Run if true
  • elif Else if
  • else Run if all false
  • fi End condition
  • Use spaces inside [ ].
  • Quote strings.
  • Use numeric operators without quotes.
  • Test before you act.
  • Make scripts smart and reliable.
TIP: Conditions make your scripts intelligent. Always test, validate, and handle every situation.
