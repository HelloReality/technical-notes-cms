7. CONDITIONAL STATEMENTS

MAKE SMART DECISIONS IN YOUR SCRIPTS.

1. Basic Syntax

The shell uses if, then, elif, else, and fi to build conditional blocks.

conditional.sh
if [ condition ]; then
  commands
elif [ condition ]; then
  commands
else
  commands
fi

2. Numeric Comparisons

Use these operators inside [ ] to compare numbers:

OpMeaningExample
-eqEqual[ $a -eq $b ]
-neNot equal[ $a -ne $b ]
-gtGreater than[ $a -gt $b ]
-ltLess than[ $a -lt $b ]
-geGreater or equal[ $a -ge $b ]
-leLess or equal[ $a -le $b ]

3. String Comparisons

Compare strings with these operators. Always quote strings! Prevents errors with spaces.

OpMeaningExample
=Equal[ "$a" = "$b" ]
!=Not equal[ "$a" != "$b" ]
-zString is empty[ -z "$a" ]
-nString not empty[ -n "$a" ]

4. File Tests

Test files and directories before acting on them:

OpMeaningExample
-fFile exists[ -f file.txt ]
-dDirectory exists[ -d /home/user ]
-eFile or directory exists[ -e /tmp/log ]
-rReadable[ -r file.txt ]
-wWritable[ -w file.txt ]
-xExecutable[ -x script.sh ]
-sFile is not empty[ -s file.txt ]
Quick Reference (Keywords)
KeywordPurpose
ifStart condition
thenRun if true
elifElse if another condition
elseRun if all false
fiEnd condition
5. Checking Services, Files, or Directories
checks.sh
# Check if a file exists
if [ -f /etc/passwd ]; then
  echo "File exists"
else
  echo "File not found"
fi

# Check if a directory exists
if [ -d /var/log ]; then
  echo "Directory exists"
else
  echo "Directory not found"
fi

# Check if a service is running
if systemctl is-active --quiet nginx; then
  echo "Nginx is running"
else
  echo "Nginx is not running"
fi
6. Practical Example

Check disk space and act based on the result.

disk-check.sh
# Check disk space and act based on the result.
USAGE=$(df / | awk 'NR==2 {print $5}' | tr -d '%')
if [ "$USAGE" -gt 80 ]; then
  echo "Disk usage is high: ${USAGE}%"
elif [ "$USAGE" -gt 60 ]; then
  echo "Disk usage is moderate: ${USAGE}%"
else
  echo "Disk usage is normal: ${USAGE}%"
fi
TIP: Conditions make your scripts intelligent. Always test, validate, and handle every situation.
