3. Creating & Running Shell Scripts
Turn commands into automation — .sh files · Shebang · chmod · Run · Permissions · Debugging · Best Practices
1. Create .sh Files
Create a new file with .sh extension. Use any text editor: nano, vim, code. Write your commands inside. 
$ nano myscript.sh
2. The Shebang #!/bin/bash
The first line of your script should be the shebang. It tells the system to use Bash to run the script. Always use this at the top! 
#!/bin/bash
3. Make It Executable
By default, scripts are not executable. Give execute permission with chmod. 
$ chmod +x myscript.sh
4. Run Your Script
Method 1 (Recommended)
$ ./myscript.sh
Method 2
$ bash myscript.sh
Tip: Use ./ when running from the current directory.

6. Common "Permission Denied" Errors
  • Script is not executable.
  • Wrong file permissions.
  • Trying to run without ./
  • Script has Windows line endings (CRLF).
  • Script saved with wrong ownership.
Fix: chmod +x myscript.sh

8. Best Practices
  • Always start with #!/bin/bash
  • Make your script executable.
  • Use full paths for important commands.
  • Add comments to explain your code.
  • Test your script step by step.
  • Use set -e to exit on error.
  • Keep scripts simple and readable.
  • Great scripts start with good habits!
