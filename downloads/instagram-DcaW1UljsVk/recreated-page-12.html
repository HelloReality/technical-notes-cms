11.WORKING WITH FILES AND DIRECTORIES

Organize. Protect. Automate.
1CHECKING WHETHER FILES EXIST

Use -f for files, -d for directories.

check.sh
if [ -f file.txt ]; then echo "File exists" fi if [ -d mydir ]; then echo "Directory exists" fi
2CREATING DIRECTORIES SAFELY

Create only if it does not exist.

mkdir.sh
mkdir -p /home/user/data/logs # -p creates parent dirs if needed
3COPYING AND MOVING FILES

Copy files or directories.

cp.sh
cp file.txt /backup/ cp -r mydir /backup/

Move or rename files.

mv.sh
mv old.txt new.txt mv file.txt /archive/
4SEARCHING FOR FILES

Find files by name.

find-name.sh
find /home/user -name "*.log"

Search by type.

find-type.sh
find /var/log -type f -name "*.log"
5FILE PERMISSIONS

View permissions.

ls-l.sh
ls -l file.txt

Change permissions.

chmod.sh
chmod 644 file.txt chmod +x script.sh
6DISK USAGE CHECKS

Check disk usage.

df.sh
df -h

Check folder size.

du.sh
du -sh /home/user/data
7CLEANING TEMPORARY FILES

Remove files older than 7 days.

find-mtime.sh
find /tmp -type f -mtime +7 -delete

Remove all files in a directory.

rm.sh
rm -rf /tmp/myapp/*
8BUILDING A SIMPLE BACKUP SCRIPT

Example: Backup a folder.

backup.sh
#!/bin/bash SOURCE="/home/user/data" DEST="/backup" DATE=$(date +%F) tar -czf "$DEST/backup-$DATE.tar.gz" "$SOURCE" echo "Backup completed: backup-$DATE.tar.gz"
Key TakeawayGood file management keeps your systems clean, safe, and reliable.
