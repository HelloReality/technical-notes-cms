11. WORKING WITH FILES AND DIRECTORIES

—— ORGANIZE. PROTECT. AUTOMATE. ——
1 CHECKING WHETHER FILES EXIST

Use -f for files, -d for directories.

bash
if [ -f file.txt ]; then
  echo "File exists"
fi
if [ -d mydir ]; then
  echo "Directory exists"
fi
2 CREATING DIRECTORIES SAFELY

Create only if it does not exist.

bash
mkdir -p /home/user/data/logs

-p creates parent directories if needed.

3 COPYING AND MOVING FILES

Copy files or directories.

bash
cp file.txt /backup/
cp -r mydir /backup/

Move or rename files.

bash
mv old.txt new.txt
mv file.txt /archive/
4 SEARCHING FOR FILES

Find files by name.

bash
find /home/user -name "*.log"

Search by type.

bash
find /var/log -type f -name "*.log"
5 FILE PERMISSIONS

View permissions.

bash
ls -l file.txt

Change permissions.

bash
chmod 644 file.txt
chmod +x script.sh
6 DISK USAGE CHECKS

Check disk usage.

bash
df -h

Check folder size.

bash
du -sh /home/user/data
7 CLEANING TEMPORARY FILES

Remove files older than 7 days.

bash
find /tmp -type f -mtime +7 -delete

Remove all files in a directory.

bash
rm -rf /tmp/myapp/*
8 BUILDING A SIMPLE BACKUP SCRIPT

Example: Backup a folder.

bash
#!/bin/bash
SOURCE="/home/user/data"
DEST="/backup"
DATE=$(date +%F)
tar -czf "$DEST/backup-$DATE.tar.gz" "$SOURCE"
echo "Backup completed: backup-$DATE.tar.gz"
