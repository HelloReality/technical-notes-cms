15. NETWORKING WITH SHELL SCRIPTS

TEST. MONITOR. ENSURE AVAILABILITY.

NETWORKING WITH SHELL SCRIPTS — TOOLKIT

Test connectivity, monitor services, and ensure availability with these essential commands.

1. CURL — HTTP REQUESTS

Send HTTP requests to endpoints.

{terminal('$ curl https://example.com\n$ curl -I https://example.com\n$ curl -s -o /dev/null -w "%{{http_code}}" URL', 'curl')}
  • Fetch URLs
  • Test APIs
  • Check headers
2. PING — CONNECTIVITY

Test if a host is reachable.

{terminal('$ ping -c 4 google.com\n$ ping -c 4 8.8.8.8', 'ping')}
  • Check reachability
  • Measure latency
  • Troubleshoot
3. SS — CHECK SOCKETS

Show network sockets and connections.

{terminal('$ ss -tuln # listening\n$ ss -tnp # connections\n$ ss -ltnp # w/ PID', 'ss')}
  • Listening ports
  • Active connections
  • PIDs
4. HOSTNAME — SYSTEM NAME

Get or set the system hostname.

{terminal('$ hostname # name\n$ hostname -I # IPs\n$ hostnamectl # details', 'hostname')}
  • Identify hosts
  • Find IPs
  • Audit fleet
5. DNS CHECKS — RESOLVE

Check DNS resolution.

{terminal('$ nslookup example.com\n$ dig example.com\n$ host example.com', 'dns')}
  • Resolve names
  • Inspect records
  • Debug DNS
6. HTTP STATUS CODES

Check HTTP response codes.

200 OK 301 / 302 Redirect 404 Not Found 500 Server Error

Use curl -w "%{http_code}" to capture status.

7. TEST ENDPOINT UP

Quickly test if an endpoint is up.

{terminal('$ curl -s -o /dev/null -w "%{{http_code}}" URL\n# 200-399 = UP\n# 400-599 = DOWN\n# 000 = no response', 'test')}
  • Verify uptime
  • Detect outages
  • Alert teams
8. APP HEALTH CHECK

Check app health endpoint.

{terminal('$ curl -s https://app/health\n$ curl -sf URL && echo OK\n || echo DOWN', 'health')}
  • Expose /health
  • Monitor apps
  • Catch issues early
9. WEBSITE SCRIPT

Sample availability script.

{terminal('#!/bin/bash\nURL="https://example.com"\nSTATUS=$(curl -so /dev/null -w "%{{http_code}}" "$URL")\nif [ "$STATUS" = "200" ]; then\n echo "UP"\nelse\n echo "DOWN"\nfi', 'avail.sh')}
10. QUICK REFERENCE

Common networking commands.

  • Test: ping, curl, nc, telnet
  • Monitor: ss, netstat, iftop
  • Ensure: /health endpoint
  • Alert: on 5xx or timeouts
  • Log: response codes & times
11. BEST PRACTICES

Network script best practices.

  • Check status codes, not just ping
  • Set timeouts on every curl
  • Log every check to file
  • Use retries for flaky links
  • Validate DNS before assuming down
  • Alert only after N failures
  • Use full URLs with protocol
12. KEY TAKEAWAY

Check network. Verify health. Ensure uptime.

Network scripts keep services reliable. Always test, monitor, and alert.

Pro tip: Combine curl, ping, and ss in one script to fully diagnose any connectivity issue.
