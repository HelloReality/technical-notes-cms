12. TEXT PROCESSING FOR DEVOPS

—— EXTRACT. FILTER. ANALYZE. AUTOMATE. ——
1 grep — SEARCH TEXT PATTERNS

Search for a pattern in files or output.

bash
grep "ERROR" app.log
2 cut — EXTRACT COLUMNS

Extract parts of each line.

bash
cut -d',' -f1 users.csv
3 sort — SORT LINES

Sort lines alphabetically or numerically.

bash
sort names.txt
4 uniq — REMOVE DUPLICATES

Remove or count duplicate lines.

bash
sort names.txt | uniq -c
5 wc — COUNT LINES, WORDS, BYTES

Count lines, words, and characters.

bash
wc -l file.txt
6 awk — PATTERN SCANNING

Extract and manipulate data.

bash
awk '{print $1, $3}' data.txt
7 sed — STREAM EDITOR

Find and replace text.

bash
sed 's/old/new/g' file.txt
8 pipes (|) — CONNECT COMMANDS

Send output of one command to another.

bash
cat app.log | grep ERROR | wc -l
Advanced Usage
9 EXTRACTING USEFUL INFO FROM COMMAND OUTPUT

Turn raw output into useful data.

List top 5 largest files

bash
du -h | sort -h | tail -n 5

Count unique IP addresses

bash
cut -d' ' -f1 access.log | sort | uniq -c | sort -nr

Show running processes summary

bash
ps aux | awk '{print $1}' | sort | uniq -c | sort -nr | head
10 SEARCHING APPLICATION LOGS

Find errors, warnings, and important events fast.

Find all ERROR lines

bash
grep "ERROR" /var/log/app.log

Find errors with line numbers

bash
grep -n "ERROR" /var/log/app.log

Count warnings

bash
grep -c "WARNING" /var/log/app.log
