12. TEXT PROCESSING FOR DEVOPS

EXTRACT. FILTER. TRANSFORM. AUTOMATE.
1 grep

Search text using patterns.

grep.sh
grep "ERROR" /var/log/app.log
2 cut

Extract columns from text.

cut.sh
cut -d: -f1 /etc/passwd
3 sort

Sort lines of text.

sort.sh
sort names.txt
sort -n -k2 scores.txt
4 uniq

Remove duplicate adjacent lines.

uniq.sh
sort file.txt | uniq -c
5 wc

Count lines, words, bytes.

wc.sh
wc -l access.log
wc -w notes.txt
6 awk

Pattern-action processing.

awk.sh
awk '{print $2}' file.txt
7 sed

Stream editor for text transforms.

sed.sh
sed 's/old/new/g' file.txt
8 pipes |

Chain commands together.

pipe.sh
cat log | grep ERR | wc -l
9 EXTRACTING USEFUL INFORMATION FROM LOGS

Pull out the data you need from massive logs.

extract.sh
grep "ERROR" app.log | cut -d" " -f3 | sort | uniq -c | sort -nr

Counts each unique error and ranks them.

10 SEARCHING APPLICATION LOGS

Find specific events by keyword or timestamp.

search.sh
grep "2025-01-15" app.log
grep -i "warning" *.log

-i = case-insensitive.

11 COMMON COMBINATIONS

Combine tools for powerful one-liners.

  • cat log | grep ERR | wc -l — count errors
  • ps aux | sort -rk4 | head -10 — top 10 memory hogs
  • df -h | awk '{print $5}' — list disk usage %
  • cut -d: -f1 /etc/passwd | sort — sorted users
  • grep -v "#" config | sed '/^$/d' — strip comments & blanks
  • du -sh * | sort -rh — biggest folders first
