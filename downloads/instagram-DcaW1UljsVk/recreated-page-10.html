9. Loops for Automation

Repeat tasks. Save time. Eliminate manual work.
1. For Loops
  • Loop through a list of items.
bash
for item in a b c; do echo "Item: $item" done
Output: Item: a Item: b Item: c
3. Looping Through Files
  • Process each file in a directory.
bash
for file in *.txt; do echo "File: $file" done
Prints all .txt files in the current directory.
5. Break
  • Exit the loop immediately.
STOP THE LOOP
bash
for i in {1..5}; do if [ $i -eq 3 ]; then break fi echo "Number: $i" done
Output: Number: 1 Number: 2
7. Avoiding Infinite Loops
  • Always update your condition.
  • Always change the variable inside the loop.
  • Use clear exit conditions.
  • Test your loops with small values first.
  • Use break when needed.
BE CAREFUL
2. While Loops
  • Repeat while a condition is true.
bash
count=1 while [ $count -le 5 ]; do echo "Count: $count" count=$((count + 1)) done
Output: Count: 1 2 3 4 5
4. Looping Through Servers
  • Run commands on multiple servers.
bash
for server in server1 server2 server3; do echo "Checking $server..." ssh $server uptime done
Check uptime on many servers.
6. Continue
  • Skip the rest of the loop and continue.
SKIP AND CONTINUE
bash
for i in {1..5}; do if [ $i -eq 3 ]; then continue fi echo "Number: $i" done
Output: Number: 1 2 4 5
8. Automating Repetitive Tasks
Loops help you automate daily tasks:
  • File management
  • Server monitoring
  • User management
  • Log analysis
  • Backups and cleanups
  • System updates
AUTOMATE EVERYTHING
KEY TAKEAWAY: Loops save time, reduce errors, and make your scripts powerful.
