10.FUNCTIONS AND REUSABLE SCRIPTS

Write once. Use many times. Stay organized.
1CREATING FUNCTIONS

Define a function using a name and () block.

functions.sh
greet() {{ echo "Hello, DevOps Engineer!" }}
2CALLING FUNCTIONS

Call the function by its name.

call.sh
$ greet Hello, DevOps Engineer!
3FUNCTION ARGUMENTS

Pass values to functions.

args.sh
greet_user() {{ echo "Hello, $1!" }} greet_user "Ann" Hello, Ann!
4LOCAL VARIABLES

Keep variables private to the function.

local.sh
calculate() {{ local num=10 echo "Inside: $num" }} calculate echo "Outside: $num" Inside: 10 Outside:
5RETURN STATUS

Functions return an exit status.

return.sh
check_disk() {{ if [ $1 -gt 80 ]; then return 1 else return 0 fi }} check_disk 90 echo "Status: $?" Status: 1
6BREAK LARGE SCRIPTS

Make scripts smaller, cleaner, and easier to read.

  • check_system()
  • backup_files()
  • deploy_app()
  • send_alert()
  • cleanup()
  • print_summary()
7REUSABLE AUTOMATION PATTERNS
  • Health checks
  • Log rotations
  • Backups
  • User management
  • Deployments
  • System cleanups
8KEEP SCRIPTS MAINTAINABLE
  • Use meaningful function names.
  • Keep functions small and focused.
  • Add comments to explain purpose.
  • Test each function before using it.
  • Reuse functions across scripts.
Key TakeawayFunctions make scripts powerful, reusable, and easy to maintain.
